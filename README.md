# Prototipos RIDI

Seis prototipos del sitio de la Red Iberoamericana de Diseño Industrial (HTML estático, sin dependencias de compilación).

- `index.html`: página comparativa
- `v1/` … `v6/`: cada prototipo (la v6 es la versión definitiva, con modo día/noche)
- `v6/fuente/`: archivos fuente de la v6 (CSS, scripts, datos y script de armado)

Contenido de muestra.
